# Data Engineer — Clearwater Analytics

Clearwater Analytics ingests retail data for hundreds of merchants.

## Requirements
- SQL: query optimization and indexing on large analytical tables
- Data pipelines: ETL/ELT design, Airflow DAGs, batch processing with Spark
- Data modeling: dimensional modeling and warehouse schema design
- Python for data tooling and glue code
- System design: design ingestion for a multi-tenant analytics platform

## Nice to have
- Kafka or streaming experience
- Distributed systems fundamentals
