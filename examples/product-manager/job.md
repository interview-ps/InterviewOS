# Product Manager — Meridian Health

Meridian Health builds scheduling software for clinics.

## Requirements
- Product sense and user research: you talk to users weekly
- Metrics: you define KPIs and run experimentation programs
- Prioritization: you make trade-offs explicit and defend the roadmap
- Communication: you align stakeholders across engineering and clinical ops
- Behavioral depth: leadership without authority, conflict resolution

## Nice to have
- SQL for self-serve analysis
- Familiarity with APIs and technical integrations
