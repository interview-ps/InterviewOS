# Senior Backend Engineer — Northwind Cloud

Northwind Cloud runs managed cloud backends for mid-size SaaS companies. You will own
backend services end to end.

## Requirements
- Strong Python: you write production Python services daily
- Designing REST APIs and HTTP endpoints that other teams consume
- SQL and relational modeling on production workloads
- Distributed systems: you reason about services that fail independently
- Caching: you have designed caching layers, tuned caches for hot paths, and reasoned about
  cache hit rates and cache-friendly data layouts
- Message queues: experience with Kafka or SQS for asynchronous work
- System design: comfortable reasoning about architecture and trade-offs in a design review

## Nice to have
- Kubernetes or container orchestration
- Observability tooling (metrics, tracing)
